## 2. 本版改了什么

UI 从 placeholder 期骨架整体换成 `design/TinyPix-4.0.pen` 的 9 个模板（详见 `CHANGELOG.md` 顶部条目）：

- 外壳三段 72 / 620 / 108，左栏 232、右栏 300、窗口 1200×800 客户区
- 视频输出、GIF、视频时间剪辑（218 高非破坏单轨时间轴）、图片处理、智能证件照、
  PDF 页面管理、OCR 与二维码识别、生成器与文件工具、设置弹窗（820×620 shell 内遮罩）

同时修掉三个会让程序"点了就退"的真实缺陷：

| 现象 | 根因 | 修法 |
|---|---|---|
| 启动即 `0xC000027B` | 缺 `portable.flag`，`InvalidOperationException` 穿透 WinRT ABI | 发行包内置哨兵；截图脚本也自动补 |
| 点工具项 `0x80004003`(E_POINTER) | `ListView.SelectionChanged` 内同步重建 `ItemsSource` 重入控件 | `DispatcherQueue` 延迟路由 + 分类切换幂等 |
| 进生成器页 NRE | XAML 里 ComboBox `SelectedIndex` 在解析期触发事件，页面下方 `x:Name` 尚未实例化 | `_ready` 就绪守卫 |

## 5. 出包命令（Windows，.NET SDK 10.0.302）

```powershell
# 单文件 exe（约 84 秒）
pwsh ./build/Publish-SingleFile.ps1

# 便携 ZIP（约 166 秒）
pwsh ./build/publish-portable.ps1
```

VM 内的实际驱动脚本（本仓库 `artifacts/vm/`）：

- `ui-publish.ps1` —— 同步 `src`/`build`/`assets` + 预置 ffmpeg 缓存包 + 跑单文件发布并打印 SHA-256
- `ui-publish-portable.ps1` —— 复用同一棵树跑便携打包并打印 ZIP SHA-256
- `ui-build.ps1` —— 仅编译（日常回归用，不打包）

ffmpeg 缓存包预置在 `C:\TinyPixBuild2\.cache\ffmpeg\`，发布脚本命中缓存后不再联网。
缓存源在 Mac 侧 `.cache/ffmpeg/ffmpeg-master-latest-win64-lgpl.zip`（113 MB），经共享目录拷入。
