# TinyPix 4.0 离线安全说明

- TinyPix 不需要账号，不上传媒体，不发送遥测，不检查在线更新。
- 应用不创建服务、计划任务、文件关联、卸载项或主动注册表配置。
- 原文件只读；历史仅保存路径、参数、状态、错误和输出路径。
- 预览与处理中间文件只写入 `Cache/`，可从设置中清理。
- 所有引擎、模型和运行库随 Portable ZIP 提供，运行时不下载依赖。
- 可用同目录 SHA-256 文件验证 ZIP，并用 `build-manifest.json` 核对包内文件。

首次在受控企业环境部署时，建议先验证 SHA-256、SBOM、第三方许可证，并在阻断出站网络的测试机中完成验收。
