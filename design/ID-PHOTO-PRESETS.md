# TinyPix 4.0 内置证件照模板设计基线

- 核验日期：2026-07-17
- 适用范围：TinyPix 4.0 离线内置证件照模板的设计、实现、测试与验收
- 基线状态：本文件是证件照模板显示名、规格参数、校验边界和限制的项目设计基线
- 来源门槛：仅采用主管机关、政府部门、驻华使领馆或政府官方 PDF/页面
- 强制原则：官方未明确的字段不得推断；产品计算值必须与官方值分开标注；“可自动校验”仅表示机器可检测，不代表主管机关必然受理

## 1. 锁定结论

| 候选模板 | 结论 | TinyPix 准确显示名 |
|---|---|---|
| 中国常用一寸 | 可内置，但不得标为通用官方证件标准 | `办公一寸（25×35 mm，非通用证件标准）` |
| 中国常用二寸 | 可内置，但不得标为通用官方证件标准 | `办公二寸（35×49 mm，非通用证件标准）` |
| 中国因私护照 | 可内置 | `中国因私护照／旅行证（33×48 mm）` |
| 美国签证 | 可内置 | `美国签证照片（51×51 mm／600×600 px）` |
| 申根签证 | 不内置泛称“申根统一规格”；改为具体国家 | `德国申根签证（短期停留，35×45 mm）` |
| 日本签证 | 可内置基础模板；不启用未经确认的数字化头部/眼位硬校验 | `日本签证（中国境内申请，35×45 mm）` |
| 加拿大签证 | 可内置纸质照片模板 | `加拿大临时居民签证纸质照片（最小 35×45 mm）` |

离线内置仅包含规格参数、校验规则、核验日期和官方链接，不打包官方徽标、示例照片或网页图片。所有官方模板在界面中必须显示“请在递交前核对主管机关最新要求；最终是否受理由主管机关决定”。

## 2. 统一像素换算规则

除美国官方明确给出数字图片像素外，下文“建议像素”均为 TinyPix 的打印换算值，不是主管机关公布的像素要求：

`像素 = 毫米 ÷ 25.4 × 300`，四舍五入到整数；输出元数据写入 300 DPI。DPI 不能改变实际像素内容，TinyPix 必须同时检查毫米尺寸、像素尺寸和打印元数据。

## 3. 模板逐项核验

### 3.1 办公一寸（25×35 mm，非通用证件标准）

- **准确显示名**：`办公一寸（25×35 mm，非通用证件标准）`
- **性质**：办公打印常用尺寸，不是对所有中国证件均有效的统一政府标准。官方实例中，全国专业技术人员资格考试报名使用“标准 1 寸”25×35 mm、295×413 px、白底；这只能证明该具体业务采用该规格，不能外推到护照、身份证、驾驶证或所有考试。
- **照片毫米**：25×35 mm（产品常用尺寸）
- **建议像素与 DPI**：295×413 px，300 DPI。该像素也与上述官方考试业务实例一致。
- **头部／脸部／眼位范围**：未找到适用于所有“一寸照”的统一官方数值；不得设置通用硬阈值。
- **背景**：模板默认提供白、蓝、红和自定义背景，但必须标注“按具体业务要求选择”；不得宣称任一颜色普遍合规。若用户选择“专业技术人员资格考试”子预设，则固定白底。
- **时间／照片新旧要求**：无通用要求；由具体业务决定。考试子预设可显示“近期”，但仅凭图片不能确认拍摄时间。
- **可自动校验项**：25:35 比例、295×413 输出像素、300 DPI 元数据、单人脸、正面程度、眼睛可见、背景均匀度、清晰度、遮挡和边缘裁切风险。
- **不可自动保证项**：照片是否“近期”、是否本人、是否未经修饰、服装是否符合具体业务、具体单位是否接受、照片纸质量。
- **官方 URL**：无锡市人力资源和社会保障局《照片格式及审核处理工具使用说明》：https://hrss.wuxi.gov.cn/doc/2022/11/09/1761316.shtml
- **核验日期**：2026-07-17
- **是否允许离线内置**：**允许，但只能放在“常用尺寸／办公打印”分组，禁止放在“官方证件”分组。**

### 3.2 办公二寸（35×49 mm，非通用证件标准）

- **准确显示名**：`办公二寸（35×49 mm，非通用证件标准）`
- **性质**：办公打印常用尺寸，不是对所有中国证件均有效的统一政府标准。官方业务实例会使用 35×49 mm，例如湖南省公安厅招聘材料明确要求“2 寸”35×49 mm、蓝底；该实例不能外推成全国所有“二寸照”的统一规则。
- **照片毫米**：35×49 mm（产品常用尺寸）
- **建议像素与 DPI**：413×579 px，300 DPI（TinyPix 换算值，非通用官方像素要求）
- **头部／脸部／眼位范围**：未找到适用于所有“二寸照”的统一官方数值；不得设置通用硬阈值。
- **背景**：默认提供白、蓝、红和自定义背景，必须由用户按具体业务选择；官方实例中的蓝底仅适用于该招聘业务。
- **时间／照片新旧要求**：无通用要求；由具体业务决定。
- **可自动校验项**：35:49 比例、413×579 输出像素、300 DPI 元数据、单人脸、正面程度、眼睛可见、背景均匀度、清晰度、遮挡和边缘裁切风险。
- **不可自动保证项**：具体业务是否把“二寸”定义为 35×49 mm、拍摄时间、身份、服装、修饰真实性、最终受理。
- **官方 URL**：湖南省公安厅《2025 年招聘警务辅助人员公告》：https://gat.hunan.gov.cn/gat/jwgk/zfxxgk/xxgkml/rsxx/202506/t20250612_33707473.html
- **核验日期**：2026-07-17
- **是否允许离线内置**：**允许，但只能放在“常用尺寸／办公打印”分组，禁止放在“官方证件”分组。**

### 3.3 中国因私护照／旅行证（33×48 mm）

- **准确显示名**：`中国因私护照／旅行证（33×48 mm）`
- **照片毫米**：宽 33 mm、高 48 mm。
- **建议像素与 DPI**：390×567 px，300 DPI（TinyPix 打印换算值；官方页面未给出该纸质照片的像素值）。
- **头部／脸部／眼位范围**：头部宽 15–22 mm；从下巴至头顶高 28–33 mm；头顶距照片上边 3–5 mm；下颚以下至照片下边不小于 7 mm。官方页面未给出眼位数值范围。
- **背景**：白色；彩色照片；面部和背景不得有阴影。
- **时间／照片新旧要求**：六个月内纸质近照；不得修改或合成。
- **可自动校验项**：33:48 比例、输出像素/DPI、头宽和头高占比、顶部间距、下颚下方间距、单人脸、正面程度、眼睛睁开、五官遮挡、背景白度与均匀度、阴影风险、清晰度、红眼、倾斜和其他物体。
- **不可自动保证项**：六个月内拍摄、申请人身份、是否真正未经修改/合成、照片纸及冲印质量、宗教头饰例外是否被正确适用、主管机关最终受理。
- **官方 URL**：中华人民共和国驻巴布亚新几内亚大使馆《护照/旅行证照片要求》（2024-01-03）：https://pg.china-embassy.gov.cn/chn/lsyw/lszj/hzlxz/hzlzyq/
- **核验日期**：2026-07-17
- **是否允许离线内置**：**允许。** 规格元数据须保存来源日期；不得打包页面示例图片。

### 3.4 美国签证照片（51×51 mm／600×600 px）

- **准确显示名**：`美国签证照片（51×51 mm／600×600 px）`
- **照片毫米**：纸质照片 2×2 英寸，官方等值标注 51×51 mm。
- **建议像素与 DPI**：数字图片官方范围 600×600 至 1200×1200 px；TinyPix 默认 600×600 px。扫描纸质照片时官方要求 300 pixels per inch。数字文件还应为 JPEG、24-bit sRGB、不超过 240 kB、压缩比不超过 20:1。
- **头部／脸部／眼位范围**：纸质照片头高（发顶至下巴）25–35 mm；眼睛水平线距照片底边 28–35 mm。数字图片头高占总高 50%–69%；眼位距底边占总高 56%–69%。
- **背景**：纯白或米白；彩色。
- **时间／照片新旧要求**：六个月内，须反映当前外貌；不得以数字增强或修改方式改变外貌。
- **可自动校验项**：正方形、600–1200 px、JPEG、文件大小、sRGB/色深、头高比例、眼位比例、居中、正面、双眼睁开、表情中性、白/米白背景、背景均匀度、眼镜、帽子/遮挡、清晰度和阴影风险。
- **不可自动保证项**：六个月内拍摄、当前外貌是否已有重大变化、身份、日常服装/宗教例外、是否经过不可检测的编辑、使领馆最终裁量。美国国务院明确说明最终是否接受由使领馆决定。
- **官方 URL**：
  - 美国国务院《Photo Requirements》：https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos.html
  - 美国国务院《Photo Composition Template》：https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos/photo-composition-template.html
  - 美国国务院《Digital Image Requirements》：https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos/digital-image-requirements.html
- **核验日期**：2026-07-17
- **是否允许离线内置**：**允许。** 纸质和数字导出模式必须在同一模板中明确区分。

### 3.5 德国申根签证（短期停留，35×45 mm）

- **准确显示名**：`德国申根签证（短期停留，35×45 mm）`
- **命名限制**：不得显示为“申根统一照片”或“全球申根签证照片”。本规则仅以德国驻华使领馆为主管来源，适用于向德国驻华使领馆申请短期申根签证的场景。
- **照片毫米**：宽 35 mm、高 45 mm。
- **建议像素与 DPI**：413×531 px，300 DPI（TinyPix 打印换算值；德国官方页面仅要求高分辨率，未给出像素/DPI数值）。
- **头部／脸部／眼位范围**：脸部占照片高度 70%–80%，即产品可按比例校验；包含下巴和脖子的正面照；脸部和眼睛不得遮挡。官方页面未给出眼位数值范围。
- **背景**：白色。
- **时间／照片新旧要求**：六个月内近照；不可后期加工；必须与实际外貌相符；不要使用之前签证申请用过的旧照片。
- **可自动校验项**：35:45 比例、建议输出像素/DPI、脸部高度 70%–80%、单人脸、正面、眼睛可见、下巴/脖子入框、白底均匀度、遮挡、清晰度和高分辨率风险提示。
- **不可自动保证项**：六个月内拍摄、是否曾用于旧申请、是否与当前外貌相符、是否后期加工、浓妆/彩色隐形眼镜的可靠判定、最终受理。
- **官方 URL**：德国驻华使领馆《短期逗留常见问题》第 19 问：https://china.diplo.de/cn-zh/service/visa-einreise/faq/faq-schengenvisa-1434980
- **核验日期**：2026-07-17
- **是否允许离线内置**：**允许，但必须按“德国申根签证”命名。** 其他申根国家需逐国核验后另建模板。

### 3.6 日本签证（中国境内申请，35×45 mm）

- **准确显示名**：`日本签证（中国境内申请，35×45 mm）`
- **照片毫米**：竖 45 mm×横 35 mm，无框。
- **建议像素与 DPI**：413×531 px，300 DPI（TinyPix 打印换算值；日本官方页面未给出像素/DPI数值）。
- **头部／脸部／眼位范围**：日本国驻上海总领事馆正文说明脸部尺寸按“头顶（含头发）至下颚”计算，并要求符合页面图示尺寸；本次可安全提取的官方正文没有给出数值范围，因此 **不设置头高、头宽或眼位数字硬阈值**。无法确认的数值不得从日本护照规格或第三方照相馆规则类推到签证。
- **背景**：日本国驻华大使馆明确要求白底；上海总领事馆要求无背景（包括阴影）。
- **时间／照片新旧要求**：提交前六个月内拍摄；脱帽、正面；照片背面写姓名。
- **可自动校验项**：35:45 比例、建议输出像素/DPI、单人脸、正面、脱帽、眼睛可见、白底均匀度、背景物/阴影、眼镜反光、太阳镜、头部遮挡、清晰度和边缘裁切风险。
- **不可自动保证项**：官方图示中的头部/眼位数值（本次未安全转录）、六个月内拍摄、背面手写姓名、与平常容貌一致、照片是否真正无修改、最终受理。
- **官方 URL**：
  - 日本国驻华大使馆《短期商务等签证（单次）》：https://www.cn.emb-japan.go.jp/itpr_zh/visa_tankishoyo.html
  - 日本国驻上海总领事馆《签证申请用照片的说明》：https://www.shanghai.cn.emb-japan.go.jp/itpr_zh/00_000905.html
  - 日本外务省签证申请表（照片框 45×35 mm）：https://www.mofa.go.jp/files/000124525.pdf
- **核验日期**：2026-07-17
- **是否允许离线内置**：**允许基础模板。** 在官方图示数值完成可复核转录前，头部/眼位只做软性风险提示，不做“合格/不合格”判定。

### 3.7 加拿大临时居民签证纸质照片（最小 35×45 mm）

- **准确显示名**：`加拿大临时居民签证纸质照片（最小 35×45 mm）`
- **照片毫米**：框幅至少 35×45 mm；TinyPix 默认输出 35×45 mm，并在界面明确“官方要求为最小尺寸”。
- **建议像素与 DPI**：413×531 px，300 DPI（TinyPix 选择的最小框幅打印换算值；该官方签证页面未规定像素/DPI）。
- **头部／脸部／眼位范围**：从下巴至头顶（crown）31–36 mm；正面全头，脸在照片中央，包含肩膀顶部。官方页面未给出眼位数值范围。
- **背景**：纯白或浅色；清晰、轮廓明确。可黑白或彩色。
- **时间／照片新旧要求**：两张相同照片，六个月内拍摄；数字照片不得以任何方式修改；须使用优质相纸打印。
- **可自动校验项**：最小 35×45 mm、建议输出像素/DPI、头高 31–36 mm、单人脸、脸居中、正面、肩膀顶部入框、表情中性、闭口、背景白/浅色及均匀度、眼睛可见、眼镜遮挡和清晰度。
- **不可自动保证项**：六个月内拍摄、两张实体照片是否完全相同、优质相纸、身份、宗教头饰例外、是否经过不可检测的修改、最终受理；需要采集生物识别信息时，申请人可能无需随申请提交纸质照片，须由具体申请流程决定。
- **官方 URL**：
  - 加拿大移民、难民及公民部《Temporary Resident Visa application photograph specifications》：https://www.canada.ca/en/immigration-refugees-citizenship/services/application/application-forms-guides/temporary-resident-visa-application-photograph-specifications.html
  - 官方 PDF：https://www.canada.ca/content/dam/ircc/migration/ircc/english/pdf/photospecs-e.pdf
- **核验日期**：2026-07-17
- **是否允许离线内置**：**允许，限定为纸质照片模板。** 不得把其他加拿大项目的数字上传像素要求混入此模板。

## 4. 不内置或不得这样命名的项目

1. **不内置“申根签证（统一）”模板。** 本次没有用统一主管机关的一手材料确认一套可覆盖所有申根成员国、所有递交地的完整照片规则；仅内置按德国官方页面核验的“德国申根签证”。
2. **不把“一寸”“二寸”放入官方证件分类。** 25×35 mm 和 35×49 mm 在具体政府业务中确实被使用，但不同证件和业务存在不同尺寸、背景、头部比例和有效期，不能推断成全国统一证件标准。
3. **不内置日本签证的数字化头部/眼位硬阈值。** 当前官方正文只指向图片中的尺寸图，未取得可复核的数字文本；不得借用日本护照规格或第三方资料补齐。
4. **不内置“自动保证合规”功能。** 软件只能输出“已通过机器可检测项／存在风险／无法判断”，不得显示“官方认证”“保证过签”“100% 合规”。

## 5. TinyPix 强制实现规则

- 每个官方模板必须保存：`presetId`、准确显示名、适用主管机关/申请场景、规格版本、核验日期、官方 URL、毫米尺寸、像素策略、背景规则、构图阈值、软/硬校验等级和免责声明。
- 检查必须分为三类：
  - **硬错误**：输出尺寸/比例/像素/文件格式超出官方明确数值；确定没有人脸或多人脸；必要区域被裁断。
  - **风险警告**：背景、阴影、姿态、眼镜反光、清晰度、表情、遮挡等算法判断。
  - **人工确认**：照片新旧、身份、是否修改、服装、宗教例外、实体打印质量和主管机关最终受理。
- 对规则可能变化的模板必须显示核验日期；离线软件不能自动更新，因此 README、模板详情页和导出说明都必须保留官方 URL，提示递交前人工复核。
