# TinyPix 4.0 UI 与交互规格

> 文档状态：Pencil 语义色、主按钮、视频时间剪辑时间轴与工具箱范围已同步；Windows 运行时验证待阶段 C/D
> 平台：Windows 10 22H2、Windows 11 x64
> 设计源：design/TinyPix-4.0.pen
> 评审导出：design/exports/1200x800、design/exports/900x600
> 默认语言：简体中文；所有可见字符串必须可本地化
> 产品边界：完全离线、解压即用、无需管理员权限、不写注册表、不自动更新

### 1.2 同模板工具共享规则

- 同一模板的工具必须复用相同壳层、区域顺序、反馈位置、队列行为和无障碍语义。
- 工具差异仅限页面标题、输入限制、预览类型、参数组、预设、主操作名称和结果动作。
- 新增工具必须先归入 8 类模板之一，不得因参数差异另建壳层。
- 只有导航层级、主流程、区域结构或全局状态语义改变时，才需要新增或重做 Pencil 代表页。

## 2. 产品交互底线

1. 首次启动进入“视频工具 > 视频输出”；以后进入最近使用的工具。不显示欢迎页或营销页。
2. 所有读取、预览、识别、处理和导出均在本机完成；界面不得出现登录、上传、云端、联网获取或在线更新入口。
3. 添加文件只记录路径并读取内容，不复制、移动、覆盖或修改原文件。移除列表项只移除引用。
4. 只有预览缩略图、波形、OCR 中间图和抽帧中间文件可写入缓存，且必须可清理。
5. 正式输出只写入用户确认的输出目录。输出路径不可写时不得启动任务。
6. 任一支持文件添加后，中央区域必须显示真实本地预览；预览未生成时显示明确进度，不回退为空拖放提示。
7. 颜色不能单独传递状态；成功、警告、失败必须同时提供图标、文本和恢复动作。
8. 长任务不阻塞界面。切换工具不丢失已添加文件、参数或队列状态。

## 3. 信息架构与主导航

### 3.1 顶部主导航

顶部栏从左到右固定为：

1. TinyPix 产品名：返回当前分类最近使用的工具，不清空草稿。
2. 图片工具。
3. 视频工具。
4. 工具箱。
5. 完全离线状态。
6. 设置。

当前分类使用 lime 背景、高对比的 on-lime 前景和文字字重共同标识。on-lime 在浅色和深色主题均为近黑，高对比主题使用 Windows 系统 HighlightText/Highlight 配对；不得使用 deep-lime 作为 lime 背景上的文字。Pencil 已新增 on-lime 变量并应用于所有荧光绿表面的文字和功能图标。顶部分类激活后打开分组工具菜单；选择工具后关闭菜单，保留应用壳层并替换中央工作台和右侧参数。

- 图片工具：图片处理、批量图片、智能证件照、背景移除、拼图/联系表、图片元数据。
- 视频工具顶层只显示三个入口：视频输出、GIF 制作、视频剪辑。时间剪辑、分割、合并拼接、画面调整、水印/字幕、音频、截图/抽帧和媒体信息作为这三个工作台内的模式/操作，不再各建独立顶层页面。
- 工具箱：PDF、OCR、二维码/条形码、屏幕录制、批量重命名副本、校验和、颜色与剪贴板、文件元数据；不提供归档压缩/解压或重复文件检测。
- 设置是独立的模态操作，不嵌入工具菜单，也不替换当前工作台；关闭后返回触发设置的控件。

每个菜单项包含统一线性图标、工具名和一句用途。菜单最多两级；同级超过 12 项时按分组分栏并提供纯本地筛选。顶部栏不随内容滚动。

### 3.2 四区桌面布局

除设置、历史详情等管理页外，所有工具共享四区工作台：

1. 左侧文件区：当前输入、最近文件入口、历史、批量任务和本地引擎状态。
2. 中央工作台：页面标题、命令栏、真实预览、编辑交互、预设或结果。
3. 右侧参数区：按任务顺序排列参数、输出位置、预估信息和唯一主操作。
4. 底部任务队列：全局任务状态、进度、取消、失败原因和输出动作。

顶部主导航是应用壳层，不计入四区。区域之间使用边框与表面色分隔，不依赖重阴影。

### 3.3 区域职责

#### 左侧文件区

- 顶部显示“文件”和当前数量。
- “添加媒体文件”是唯一主按钮；批量工具允许邻近次操作“添加文件夹”。
- 文件项展示缩略图、文件名、必要元数据、状态和更多菜单。
- 文件名最多两行；截断时 Tooltip 与 Narrator 提供完整名称。
- 最近文件只保存路径。路径失效时显示“原文件不存在”，不得自动搜索全盘。
- 底部显示当前工具所需引擎/模型状态；异常时提供“查看修复说明”。

#### 中央工作台

- 标题区包含工具名、一句本地处理说明和不超过 3 个上下文命令。
- 空状态提供拖放目标和“添加文件”键盘替代。
- 有文件后，空状态必须被真实预览替换。
- 预览下方只展示当前选择的名称、格式、尺寸、时长或页数等摘要。
- 预设卡片是快捷参数，不是第二套导航。900×600 下可折叠到右侧下拉。
- 编辑命令超过宽度时进入“更多”，不得横向滚动。

#### 右侧参数区

- 参数按“主要参数 → 高级参数 → 输出”排列，复杂项默认折叠在高级分组。
- 每个输入必须有持久标签；参数错误显示在字段下方，并在主按钮旁提供摘要。
- 主操作固定在参数区底部可见位置；一个页面只有一个主操作。
- 执行后主操作进入禁用/处理中状态且不改变宽度；取消位于任务队列。

#### 底部任务队列

- 队列跨工具存在，不因导航切换消失。
- 折叠态显示任务数、活动任务摘要和展开按钮；有失败时同时显示失败数量。
- 展开态按“执行中 → 等待中 → 失败 → 已完成”排列，同组按创建时间升序。
- 单项显示输入名、工具、关键格式、进度、状态文本、取消/重试/打开输出和更多菜单。
- 进度不可确定时使用不确定进度条并显示阶段，不伪造百分比。

## 4. 八类页面模板

### 4.1 转换/压缩工作台

适用视频输出、图片转换/压缩、音频提取、媒体元数据清理等顺序处理工具。

- 中央为单文件真实预览；多选时显示当前项，可从左侧切换。
- 右侧至少含输出格式、质量/编码、尺寸或保留原始、输出目录。
- 预设一次性写入声明的参数；写入后显示“参数已修改”。
- 主操作使用结果文案，如“开始输出”“转换图片”，不使用泛化的“确定”。

### 4.2 时间轴编辑工作台

适用 GIF，以及“视频剪辑”工作台中的时间剪辑、分割、合并拼接、倍速、替换音频、字幕烧录、水印、截图和抽帧。

- “视频剪辑”只有一个路由和一套工作台，顶部模式切换为“时间剪辑 / 合并拼接”；不得为 `video.trim`、`video.split`、`video.merge` 创建重复页面。
- 时间剪辑模式使用单源时间轴；合并拼接模式将同一区域切换为多文件有序片段轨，支持拖动和键盘排序、逐项预览、兼容性预检与统一编码。两种模式共享左文件区、预览、右侧输出和任务队列。

- 中央保留视频画面、播放控制、时间码和单轨时间轴；“视频时间剪辑”必须显示缩略图轨、波形、播放头、入点、出点与保留片段，不能退化为普通范围滑块。
- 时间轴命令固定为：撤销、重做、设为入点、设为出点、在播放头分割、删除/恢复片段、缩小、放大、适应窗口。
- 交互模型采用轻量单轨“保留片段”：绿色片段参与导出，灰色区间跳过；Delete 只切换“排除/恢复”，不删除源文件或制造不可恢复状态。
- 时间轴获得焦点时：Space 播放/暂停，J/K/L 后退/暂停/前进，I/O 设置入点/出点，B 在播放头分割，Delete 排除/恢复所选片段，Ctrl+Z/Ctrl+Y 撤销/重做，`+`/`-` 缩放；输入框获得焦点时不得抢占字符快捷键。
- 左/右方向键按 1 秒定位，Shift+左/右逐帧定位，Ctrl+左/右跳到前/后关键帧；所有快捷键同时出现在按钮工具提示和快捷键帮助中。
- 入点、出点和播放头可键盘精确调整；时间码使用等宽数字。
- 全部缩略图、波形、片段、入点、出点和播放头共用同一个源时间坐标系；横向位置必须由源时间戳换算，禁止按视觉均分或手工摆放。缩略图、波形和片段轨不得重叠。
- 入点、出点和播放头必须使用不同形状/标签/前景共同区分；入点前与出点后的区域标记为“范围外”，所选片段显示“已选”。空闲态不得高亮“分割”等一次性命令。
- 拖动时间轴必须有数字输入或键盘替代。
- 导出默认“关键帧优先”：显示请求边界与实际关键帧边界并使用 stream copy；用户选择“精确到帧”时显示“精确边界自动重编码”，同时展示预计体积和耗时变化。
- 不提供多轨、波纹编辑、滚动编辑、转场、关键帧动画或项目工程文件；合并拼接仅使用同一工作台中的有序片段轨，不膨胀为专业 NLE。
- 合并工具以左侧列表顺序输出，并提供键盘上移/下移。

### 4.3 图片编辑工作台

适用缩放、裁剪、旋转、翻转、颜色调整、透明度、水印、拼图和联系表。

- 中央显示可缩放画布、画布边界和编辑命令栏。
- 裁剪框同时提供拖柄与数字输入。
- 原图/处理后对比可聚焦，不使用仅悬停交互。
- 批量处理明确区分“应用到当前项”和“应用到全部”。

### 4.4 智能证件照工作台

适用一寸、二寸、护照、签证、自定义证件照、背景替换和打印排版。

- 固定流程：添加原图 → 本地人脸检测 → 选择模板/背景 → 构图校验 → 预览输出 → 生成。
- 中央叠加头部比例、安全边距和裁切框；所有校验同时显示文字。
- 右侧显示物理尺寸、像素、DPI、背景、头部比例、边距和排版。
- 多人、无人脸、侧脸、低分辨率分别提供重新选图、选择人脸、手动校正或按风险继续。
- 输出明确区分原图、透明结果、标准照和五寸/六寸排版照。

### 4.5 PDF 页面管理工作台

适用合并、拆分、排序、旋转、水印和图片互转。

- 中央使用页面缩略图网格或单页预览，显示页码和总页数。
- 拖排同时提供“上移/下移/移到开头/移到末尾”键盘菜单。
- 删除页面只影响待输出文档，不修改源 PDF；执行前展示输出页数。
- 加密、损坏或不支持的 PDF 在添加阶段阻止执行并给出原因。

### 4.6 OCR/二维码识别工作台

适用图片 OCR、扫描 PDF OCR、二维码和条形码扫描。

- 中央显示来源预览和可选择的识别结果。
- 识别范围、语言、页面范围和旋转校正位于右侧。
- 结果标明页码/区域；低置信内容使用图标与文本。
- 复制、保存文本和重新识别是次操作；识别过程可取消。

### 4.7 生成器与文件工具工作台

适用二维码/条形码生成、批量重命名副本、校验和、颜色转换、剪贴板图片保存、元数据、屏幕录制。

- 无媒体预览需求时，中央改为输入/结果区，但保留四区关系。
- 生成器实时预览完全由本地输入产生；参数非法时保留上次有效预览并显示字段错误。
- 二维码生成使用文本输入或 UTF-8 TXT 导入，中央显示实时二维码预览，输出明确为 PNG/SVG；纠错级别固定使用 L/M/Q/H 离散单选，不得使用连续质量滑块。
- 二维码生成的预览、主操作和任务行均使用二维码语义图标，不得使用播放图标、媒体播放器进度条或 PDF 元数据；输入名称、预览说明、参数和任务名称必须指向同一输入。
- 文件工具执行前提供变更预览。file.rename 的语义固定为“在输出目录创建重命名副本”：不得重命名、移动、覆盖或删除原文件；新名称冲突时按通用同名规则自动追加“ (n)”。
- 工具箱不提供重复文件检测、重复文件删除或全盘扫描入口。
- 工具箱不提供 ZIP、RAR、7z 等归档压缩或解压入口；媒体压缩仍属于视频/图片/PDF各自工具，不归入工具箱。
- 屏幕录制前显示区域、音频来源、保存位置和倒计时；停止后进入普通输出状态。

### 4.8 设置弹窗、历史和缓存管理页面

- 设置由顶部齿轮或 Ctrl+, 打开应用内模态弹窗；不导航离开当前工具，不清空输入、参数、预览或队列。
- 产品内只有一个设置入口、一个设置弹窗和一套保存逻辑。1200×800、900×600 与 High Contrast 画板只是同一弹窗的规范/响应/主题证据，不得实现为多个页面或多个 ViewModel。
- 设置不复用媒体预览、右参数栏或任务队列模板；弹窗内不得出现播放、人物、齿轮占位预览等与设置无关的图标。
- 弹窗固定分组：常规、输出、缓存与历史、引擎、许可证与离线安全；标准布局左侧分类，900×600 紧凑布局改为顶部分类。
- 模态遮罩覆盖完整 `XamlRoot`（包括顶部导航），背景工作台与导航均不可交互。High Contrast 下当前分类使用系统 `Highlight` / `HighlightText`，普通离线说明使用 `Window` / `WindowText` 中性信息样式，不借用成功绿色。
- 开关除系统轨道和滑块外同时显示开/关文字；键盘焦点使用系统焦点矩形，不能只靠填充色或阴影表达。
- Esc、右上角关闭或“取消”放弃本次未保存改动；“保存设置”先校验，成功后关闭并返回触发设置的控件。窗口关闭期间背景工作台不可操作。
- 历史、批量任务和缓存明细仍是管理页，可用列表/详情替代媒体预览，但不伪装为媒体工作台。
- 历史按时间倒序，支持按工具、状态、日期本地筛选。
- 历史只显示路径、参数摘要、状态、输出路径和时间，不暗示保存原媒体副本。
- 清理缓存显示可释放空间和缓存类型；不得删除原文件或正式输出。
- 许可证可离线查看、搜索、复制和导出，网络链接不能是唯一阅读方式。

### 6.2 字体、字号、间距与形状

- UI 字体 font-ui = Segoe UI Variable；中文回退 font-cjk = Microsoft YaHei UI；不得加载远程字体。
- 字号：type-title 24、type-section 16、type-body 14、type-label 12、type-status 11。
- 间距：space-4/8/12/16/20/24/32，只使用该 4/8 递进体系。
- 圆角：radius-6/10/14/18；胶囊按钮使用控件完整圆角。
- 图标：icon-sm 16、icon-md 20、icon-lg 24，同层级保持统一线性风格。
- 标准控件高 control-height 40；可点击目标最小命中区 touch-target 44。

### 6.3 交互视觉

- Hover 只改变表面、前景或透明度，不移动控件。
- Pressed 反馈在 100ms 内出现，不造成尺寸跳动。
- Focus 使用 2px focus 外环及 1px 分离间隔；高对比度遵循系统焦点矩形。
- Disabled 保留可读标签、降低强调并移除交互；Tooltip 说明原因。
- 功能性状态过渡 150–250ms；减少动态效果开启时立即切换。
- 普通文字与其背景的对比度不得低于 4.5:1。
- 传递操作或状态含义的功能图标、输入边框、按钮边界和焦点边界与相邻背景的对比度不得低于 3:1。
- `border` 仅用于装饰分隔；其 Light 1.52:1、Dark 1.86:1 不得承担控件识别。功能边界统一引用 `control-border`（Light 3.44:1、Dark 3.36:1），高对比模式改用系统 `WindowText`/控件边框资源。
- 视频预览、时间轴和波形使用固定 `media-stage`；其时间码、起止刻度和功能图标统一引用 `on-media`，不得继承页面 `ink`。高对比模式由系统 `Window` / `WindowText` 接管。
- 荧光绿 lime 背景上的文字和功能图标必须使用 on-lime 近黑前景；不得使用白色、浅绿色或 deep-lime 作为该表面前景。
- 白色或浅色按钮上的功能图标必须使用 ink/on-surface 近黑前景，不得使用荧光绿。
- 可复用主按钮使用 `action-primary` + `on-action-primary`：浅色和普通深色主题均保持深色底、酸橙文字/图标，避免同一动作在不同深色页面出现白底或黑底漂移；高对比模式交由系统按钮资源。
- 荧光绿功能图标只可用于与其达到至少 3:1 对比度的深色背景，或置于具有足够对比描边/深色容器的独立图标表面；不能直接放在白色或浅色底上。
- 状态不能只靠颜色表达；选中、成功、警告、失败、离线和禁用必须同时使用文字、图标、形状、边框或控件状态中的至少一种非颜色线索。

### 6.4 按钮与选择状态矩阵

| 类型 | Default | Hover / Pressed | Focus | Disabled / Loading |
|---|---|---|---|---|
| 当前分类 | `lime` + `on-lime` + 加粗文字 | 使用原生状态层，前景保持 `on-lime` | 2px 系统焦点框 | 不作为可禁用业务动作 |
| 主操作 | `action-primary` + `on-action-primary` | 只改变原生状态层，不改变尺寸和语义前景 | 2px 系统焦点框 | Disabled 保留标签；Loading 禁止重复执行并显示进度环和“处理中” |
| 次操作 | `surface` + `ink` + `control-border` | 原生表面状态层 | 2px 系统焦点框 | 降低强调并给出不可用原因 |
| 危险操作 | `danger` + `on-danger` + 动作文字 | 原生危险状态层 | 2px 系统焦点框 | 不只依赖透明度区分 |
| 图标按钮 | 所在表面 + 可读前景；命中区至少 44×44 | 原生表面状态层 | 2px 系统焦点框 | 保留 Tooltip 和 Automation Name |
| 选中文件/预设 | `control-border` 描边 + 勾选/状态图标 + 文字，不使用主按钮实心样式 | 仅改变表面或描边 | 容器焦点框与选中标记同时可见 | 明确文字说明不可用原因 |

高对比模式下本矩阵的品牌颜色全部交由 Windows `Highlight` / `HighlightText`、`ButtonFace` / `ButtonText`、`Window` / `WindowText` 接管，且保留文字、图标、描边和焦点矩形。

## 7. 浅色、深色与高对比度

普通深色主题使用深灰分层表面和 TinyPix 酸橙色强调；纯黑背景配黄色高亮属于 Windows 高对比度主题，由系统 `Highlight` / `HighlightText` 接管，二者不得混作同一主题或互相复制颜色。

1. 设置提供“跟随系统、浅色、深色”，默认跟随系统；高对比度由系统自动接管。
2. 主题切换即时生效并保留文件、参数、预览位置和焦点。
3. 普通文字对比不低于 4.5:1；功能图标和控件边界不低于 3:1。大文本可按无障碍标准使用不低于 3:1，但不得因此降低普通正文要求。
4. 深色模式不简单反色；媒体预览保持深色舞台，面板由 canvas/surface/surface-muted/border 分层。
5. 高对比度不用阴影表达层级，使用系统边框；选中、错误、成功均有文本或图标。
6. 媒体内容不做主题滤镜；透明图片使用可切换棋盘格背景。
7. 三种主题均检查标题、输入、选中、焦点、禁用、进度、成功、警告、失败和对话框。

## 8. 文件添加、拖放与真实预览

### 8.1 添加入口

- 支持按钮、拖放和快捷键三种等价方式。
- 文件对话框按当前工具过滤，同时允许选择“所有文件”以显示明确的不支持错误。
- 批量工具可添加文件夹；扫描前显示范围，扫描中可取消，结果按稳定文件名顺序加入。
- 重复添加同一路径时聚焦已有项并提示“文件已在列表中”，不创建副本。

### 8.2 拖放反馈

- 拖入窗口时只在当前工具可接收区域显示“释放以添加”。
- 不支持项目在释放前显示禁止指针；混合拖放接收支持项并逐项列出拒绝项。
- 拖放文件不会立即启动处理。
- 拖放重排只在合并、PDF 页面和显式排序列表中生效。

### 8.3 预览规则

- 图片：先显示本地缩略图，再替换清晰预览。
- 视频：显示本地可播放画面、时长和时间码。预览器不能解码时，本地 FFmpeg 生成缩略图，并提示“当前预览器无法播放此编码，仍可使用本地引擎处理”。
- 音频：显示本地波形或封面/占位图，明确时长和音轨。
- PDF：显示本地页面缩略图，首屏优先，后续按需写入缓存。
- OCR/二维码：显示来源图和识别区域。
- 文件工具：显示变更前后预览或本地计算结果。
- 预览失败时保留文件项，显示原因、重试和“查看文件信息”，不得恢复为空状态。

## 9. 参数、预设与批量行为

- 参数在离开字段或按 Enter 时校验；非法值立即阻止执行，但不在每次按键时弹窗。
- 修改默认值后显示“参数已修改”；重置只恢复当前工具默认值，不清空文件。
- 选择预设时只覆盖该预设声明的字段；应用后提供一次撤销。
- 自定义预设保存前显示名称和参数摘要；预设同名时要求用户改名或明确更新该预设。该行为仅针对参数预设，不代表允许覆盖媒体或文件输出。
- 批量任务默认共享参数；允许逐项例外时，文件项显示“自定义参数”标记。
- “应用到全部”只影响当前文件列表，不更改全局默认，并提供撤销。
- 所有输出在入队前做绝对路径、大小写、分隔符、点段和符号链接解析后的规范化路径比较。任何输出与任一输入的规范化路径相同，必须永远拒绝执行，且不提供确认、覆盖或忽略入口。
- 普通同名输出固定在文件主名后追加“ (n)”，n 从 1 开始选择第一个未占用名称，例如“图片 (1).png”；用户界面不提供通用覆盖选项。
- 序列输出固定使用下划线加三位序号，从 _001 开始，例如“帧_001.png”“页面_001.png”；超过 999 时继续自然扩展为 _1000，不回卷、不覆盖。
- 逐工具的基础文件名、扩展名和多输出变体由 FEATURE-MATRIX.md 定义；在该矩阵完成并与本规则一致前，逐工具输出命名不得冻结。
- 参数变化更新本地预估；不能可靠预估时显示“将在处理时确定”，不显示虚假数值。

## 10. 任务队列与取消

### 10.1 状态模型

任务状态固定为：

- 草稿：已选文件和参数，尚未入队。
- 等待：校验通过，等待执行。
- 执行中：正在读取、分析、处理或写入。
- 取消中：已请求取消，等待安全停止和临时文件清理。
- 成功：正式输出已验证存在。
- 失败：当前任务失败，不影响其他任务。
- 已中断：应用上次退出时未完成，可手动重试。

不提供伪暂停。引擎不能安全暂停时只提供取消；重试创建新任务记录并保留原失败记录。

### 10.2 并发与进度

- 媒体重任务默认同时执行 1 个，轻量文件任务默认同时执行 2 个。
- 当前步骤和总进度均可得时显示百分比；仅有阶段时显示不确定进度条和阶段名称。
- 批量任务显示总体完成数与当前项，如“8/24，正在处理 09.jpg”。
- 单项失败不停止后续项；最终显示“部分失败”。

### 10.3 取消

- 等待任务取消后立即离开等待队列并标记“已取消”，不产生输出。
- 执行中任务进入“取消中”，取消按钮禁用，状态说明“正在安全停止”。
- 取消只删除该任务创建且尚未完成的临时文件，不删除原文件、其他任务缓存或已成功输出。
- 若引擎已完成输出原子替换，则任务记为成功，并明确说明输出已完成。
- 关闭应用时若有活动任务，显示任务数，并提供“返回应用”“取消任务并退出”，不得静默强退。

| 08 | 批量部分失败 | 成功/失败数、队列已继续 | 查看失败项 | 公告两类数量，不停止剩余项 |
| 09 | 文件格式不支持 | 文件名、检测类型、允许输入 | 查看允许的输入类型 | 焦点到恢复动作 |
| 10 | 原文件不存在 | 原路径、未处理状态 | 重新定位文件 | 历史项保留，公告路径失效 |
| 11 | 输出目录不可写 | 目录、可能原因 | 选择可写位置 | 聚焦路径选择器，修复前禁用执行 |
| 12 | 磁盘空间不足 | 预计需要、当前可用 | 更换目录或清理缓存 | 公告两个容量值，不自动清理 |
| 13 | 引擎/模型缺失或损坏 | 组件名、本地校验失败 | 查看修复说明 | 禁用受影响工具，其他工具可用 |
| 14 | 缓存清理与许可证提示 | 缓存边界、许可证可导出 | 清理缓存或导出声明 | 清理前确认，完成后公告空间 |

### 11.1 消息严重级别

- 信息：中性表面，说明情况，不要求立即处理。
- 成功：success + 对勾图标 + 结果动作。
- 警告：warning + 警告图标 + 可继续/修复选择。
- 错误：danger + 错误图标 + 明确恢复动作。
- 离线：常驻状态使用成功或系统状态色和文字“完全离线”，不是联网故障提示。

## 12. 错误恢复规则

1. 错误先定位到文件或字段，再在页面摘要汇总，不得只弹出阻塞对话框。
2. 消息必须包含下一步：重试、重新定位、修改参数、更换目录、释放空间或查看修复说明。
3. 多字段错误时，摘要列出数量，激活后依次聚焦错误字段。
4. 重试沿用原参数并重新校验；原文件已变化时先重新生成预览。
5. 引擎异常只禁用依赖该引擎的工具；壳层、历史、设置和无关工具可用。
6. 失败不自动删除记录；历史和队列保留原因。
7. 对话框仅用于清理缓存、删除历史记录、退出时有活动任务等确认动作；媒体和文件输出不存在通用覆盖确认。
8. 对话框默认焦点在非破坏性操作；Esc 关闭且不执行更改。

## 13. 键盘、焦点与快捷键

### 13.1 Tab 与区域顺序

默认 Tab 顺序严格跟随视觉阅读顺序：

1. 顶部主导航。
2. 左侧：添加 → 页签/快捷入口 → 文件列表 → 引擎状态。
3. 中央：标题命令 → 预览控制 → 编辑命令 → 预设/结果。
4. 右侧：从上到下参数 → 输出目录 → 主操作。
5. 底部：展开/折叠 → 任务项 → 单项操作。

F6 在“顶部、左侧、中央、右侧、底部”五区循环，Shift+F6 反向。区域内部用 Tab；菜单、列表、预设、时间轴和页面网格用方向键。不得创建键盘陷阱。

### 13.2 全局快捷键

| 快捷键 | 动作 |
|---|---|
| Ctrl+O | 添加文件 |
| Ctrl+Shift+O | 当前工具支持批量时添加文件夹 |
| Ctrl+1 | 图片工具 |
| Ctrl+2 | 视频工具 |
| Ctrl+3 | 工具箱 |
| Ctrl+, | 设置 |
| Ctrl+H | 历史记录 |
| Ctrl+J | 展开并聚焦任务队列 |
| Ctrl+Enter | 参数有效时将当前任务加入队列 |
| Ctrl+R | 重试当前选中的失败或中断任务 |
| Ctrl+Shift+E | 打开当前成功任务的输出文件夹 |
| Delete | 从当前列表移除选中项，不删除磁盘文件 |
| Space | 焦点在媒体预览时播放/暂停 |
| 主键盘 Ctrl+= / Ctrl+- | 焦点在图片/PDF 预览时放大/缩小；Ctrl+= 表示主键盘加号所在键，不要求 Shift |
| 数字小键盘 Ctrl+Add / Ctrl+Subtract | 与主键盘缩放完全等价 |
| Alt+Left | 返回上一工具并恢复其选择、滚动和参数 |

快捷键不得覆盖 Windows 系统和 Narrator 组合键。不可用时不执行，并由状态区说明原因。

### 13.3 焦点管理

- 导航到新工具后焦点移到中央页面标题；Narrator 先读工具名再读说明。
- 添加成功后焦点保持在添加入口并礼貌公告；首个错误发生时才移到错误摘要。
- 对话框打开时焦点进入；关闭后返回触发控件。
- 任务完成不强抢当前输入焦点，只礼貌公告；用户打开结果时聚焦结果标题。
- 删除列表项后聚焦下一项；无下一项则上一项；列表为空则聚焦添加按钮。
- 折叠包含焦点的区域前，先把焦点移到其展开按钮。

## 14. Narrator 与无障碍名称

所有交互控件使用 WinUI 原生语义，并设置可本地化的 AutomationProperties.Name；必要时设置 HelpText、ItemStatus、PositionInSet 和 SizeOfSet。

|---|---|
| 顶部分类 | “视频工具，已选择，打开工具菜单” |
| 离线状态 | “完全离线，应用不会连接网络或上传文件” |

| 预览区域 | “企业宣传片.mp4 本地视频预览” |
| 播放按钮 | “播放企业宣传片.mp4”或“暂停企业宣传片.mp4” |

- 列表、页面网格和时间轴提供数量、位置和选中状态。
- 文本缩放至 200% 时允许纵向滚动和换行，不裁切主操作、错误和焦点目标。

## 15. 设置、历史、缓存、许可证与离线说明

### 15.1 设置

- 打开方式：右上角齿轮或 Ctrl+,；使用模态设置弹窗覆盖当前工作台，不创建独立窗口或媒体工作台页面。
- 焦点：打开后聚焦当前分类首个设置项；Tab 只在弹窗内循环；Esc/取消关闭并返回触发设置的控件。
- 输出目录：显示完整路径、浏览、恢复默认和可写性校验。
- 便携数据：只读显示数据根目录、便携模式和“所有可变数据写入应用目录”。
- 缓存：显示上限、当前占用、分类占用和清理入口；默认上限 5 GB。
- 历史：最近文件上限 200、处理历史上限 1000；清空记录不影响原文件和输出。
- 引擎与模型：逐项显示内置版本、校验状态和本地路径；不提供在线下载或更新。
- 外观与无障碍：跟随系统/浅色/深色、减少动态效果；界面密度使用系统默认。
- “保存设置”执行整体验证；路径或数值无效时不写入、保持弹窗打开并聚焦首个错误字段。成功后关闭弹窗，以壳层 InfoBar 提示“设置已保存”。

### 15.2 历史记录

- 列表字段：时间、工具、输入路径、参数摘要、状态、输出路径。
- 打开历史项时重新检查输入和输出；不存在时分别显示“重新定位”和“选择新输出位置”。
- “再次处理”创建草稿并恢复参数，不立即执行。
- 删除历史只删除数据库记录；确认文案明确“不删除原文件和输出文件”。

### 15.3 缓存

- 分类：预览缩略图、视频缩略图/波形、PDF 页预览、OCR 中间图、未完成任务临时文件。
- 清理前显示预计释放空间；执行期间显示进度，可取消尚未开始的分类。
- 活动任务使用的缓存不删除，标记为“任务完成后可清理”。
- 清理完成显示实际释放空间；失败项可重试。

### 15.4 许可证与离线安全

- 显示 TinyPix 版本、第三方组件/模型名称、版本、许可证和本地声明。
- 支持本地搜索、复制和导出 THIRD_PARTY_NOTICES.txt；无网络也能阅读完整内容。
- 离线说明固定陈述：无账号、无遥测、无自动更新、无云 API、不会上传用户文件。
- 显示数据边界：仅保存最近路径、参数、处理记录、输出路径及可清理的预览/临时缓存。
- 引擎损坏仅指导重新解压完整安装包或由管理员替换已校验文件，不提供联网下载按钮。

## 16. 设计变更与冻结流程

### 16.1 普通修订

### 16.3 同步要求

每次正式 UI 变更必须在同一变更集中完成：

1. 更新 design/TinyPix-4.0.pen。

5. 记录原因、受影响模板、验证尺寸和无障碍结果。
