## ✨ 功能特性

- 🖼️ **图片压缩** — 支持 PNG / JPG / WebP / BMP / PSD / AI / SVG
- 📝 **文字叠加** — 在图片上添加文字水印（位置/颜色可选）
- 📐 **缩放比例** — 输出尺寸按比例调整（原始 / 50% / 75% / 100% / 150% / 200% / 自定义）
- 🎬 **视频压缩** — MP4 / MOV / AVI 视频压缩
- 🎞️ **GIF 制作** — 视频片段转 GIF
- 🖥️ **AI 文件** — 支持 Illustrator (.ai) 文件渲染导出
- 🎨 **Apple 风格 UI** — 简洁美观的 macOS 设计语言

## 🔧 技术栈

- **前端**：PySide6（Qt for Python）
- **图片处理**：Pillow、Pillow-HEIF、Pillow-SIMD
- **视频处理**：FFmpeg（内置）
- **打包**：PyInstaller
